# جاده ۱۴۰۵ — JADDEH 1405

پروژهٔ توسعه‌ای بازی سفر جاده‌ای با فضای ایرانی و هدف انتشار مستقل برای Windows.

## محتوای مخزن فعلی
- `README.md`: معرفی پروژه و وضعیت صادقانهٔ بیلد.
- `Models/Vehicle_Catalog_47.csv`: فهرست ۴۷ وسیله نقلیه همراه ابعاد اسمی و وضعیت دقت مدل‌ها.

## وضعیت پروژه
این مخزن هنوز شامل بسته کامل باینری ۱۲۶ مگابایتی یا فایل EXE نیست. مخزن اولیه با README و کاتالوگ شروع شده است. انتقال فایل‌های بزرگ مدل‌ها و خروجی اجرایی باید از طریق Git LFS یا GitHub Releases انجام شود؛ اتصال فعلی GitHub در این گفتگو فقط عملیات فایل متنی را در اختیار می‌گذارد.

## سطح دقت مدل‌ها
- پراید ۱۳۱: بازسازی رویه‌ای پرجزئیات با قطعات مستقل؛ اسکن کارخانه یا CAD رسمی نیست.
- سایر ۴۶ وسیله: مدل‌های رویه‌ای مستقل برای نمونه‌سازی؛ فوتورئالیستی یا بازسازی ۱:۱ نیستند.
- تکسچرهای 4K کامل و اختصاصی برای همه خودروها وجود ندارد.

## نیازمندی‌های هدف
- رانندگی آزاد و سفر جاده‌ای
- پیاده‌شدن اول‌شخص و تعامل دستی با اشیا
- باز و بسته شدن در، کاپوت و صندوق
- تعمیر و تعویض قطعات
- ذخیره و ادامهٔ سفر
- محیط و علائم و خودروهای ایرانی

## دانلود
